# React Native Labs:

Repository tổng hợp 9 bài thực hành **React Native với Expo**, được thực hiện trong quá trình học và làm quen với phát triển ứng dụng di động.

Các bài thực hành tập trung vào giao diện, xử lý tương tác người dùng, quản lý trạng thái, animation, âm thanh, game logic, tính toán và kết nối API.

---

## Công nghệ sử dụng

- React Native
- Expo
- TypeScript
- JavaScript
- Expo Audio
- Open-Meteo API
- Visual Studio Code

---

## 📚 Danh sách bài thực hành

Lab 1:I Am Rich -> Hiển thị hình ảnh, tương tác và animation 
Lab 2: MiCard -> Thiết kế danh thiếp cá nhân 
Lab 3: Dice -> Xúc xắc ngẫu nhiên và tính tổng 
Lab 4: Magic 8 Ball -> Nhập câu hỏi và trả lời ngẫu nhiên 
Lab 5: Xylophone -> Phát âm thanh khi tương tác với các phím 
Lab 6: Quizzler -> Trắc nghiệm Đúng/Sai, tính điểm và câu hỏi ngẫu nhiên 
Lab 7: Boss Level Challenge 2 -> Game, timer, mạng, combo và mục tiêu di chuyển 
Lab 8: BMI Calculator -> Nhập dữ liệu, tính BMI và hiển thị kết quả 
Lab 9: Clima -> Tra cứu thời tiết thông qua API

Cách chạy project
1. Clone repository
git clone https://github.com/B1t-Phun/React-Native-Labs.git
2. Di chuyển vào thư mục project
cd React-Native-Labs
3. Chọn Lab muốn chạy

Ví dụ chạy Lab 9:

cd Lab9
npm install
npx expo start

Có thể thay Lab9 bằng Lab1 đến Lab9 tùy bài muốn chạy.

Sau khi Expo khởi động:

Nhấn a để chạy trên Android
Nhấn w để chạy trên Web
Quét mã QR bằng Expo Go để chạy trên điện thoại
